An entry for the [make.fun bounty "One Emoji, One Smile"](https://make.fun/bounty/u-0xkianno-one-emoji-one-smile-5470751f): entrants send exactly one emoji and nothing else, and a judge model picks the warmer of each pair. This entry sends one emoji — 🥰 (U+1F970, smiling face with hearts) — a genuine smile with smiling eyes and three hearts: warmth and affection drawn on the face itself. It reads as a smile first and a heart second, in every culture and at any size.

## Run it

```sh
python3 main.py
```

That prints exactly one emoji (plus a trailing newline) and exits 0. Python 3.13, standard library only, no arguments, no input, no network. The output is deterministic — two runs produce identical bytes.
